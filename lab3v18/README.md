# Лабораторна робота №3

## Тема

Реалізація інтерфейсу `IDisposable` та патерну Dispose у C#.

## Мета

Ознайомитися з принципами управління ресурсами у .NET, навчитися реалізовувати патерн Dispose для коректного звільнення керованих і некерованих ресурсів, а також дослідити роботу збирача сміття (Garbage Collector) та деструктора.

## Варіант

18 — MemoryStream (спрощений)

## Завдання

Створити клас `MyMemoryStream`, який імітує потік у пам’яті та реалізує інтерфейс `IDisposable`.

Клас має:
* приватне поле `_buffer` — буфер у пам'яті (`byte[]`);
* приватне поле `_isOpen` — стан потоку (`bool`);
* приватне поле `_disposed` — прапорець звільнення ресурсів (`bool`);
* властивості `IsOpen` та `Capacity`;
* конструктор, що "виділяє ресурс" (ініціалізує буфер та встановлює `_isOpen = true`);
* методи `Write(byte[] data)` та `Read()`;
* захищений віртуальний метод `Dispose(bool disposing)`;
* метод `Dispose()` для звільнення ресурсів;
* деструктор, що викликає `Dispose(false)`.

Продемонструвати роботу в методі `Main`:
* створення об'єктів з використанням `using`;
* створення об'єктів без `using` та явний виклик `Dispose()`;
* створення об'єкта без виклику `Dispose()` з демонстрацією роботи деструктора через `GC.Collect()`.

## Хід роботи

Було створено клас `MyMemoryStream`.

У класі використано приватні поля:
* `_buffer`;
* `_isOpen`;
* `_disposed`.

Також було створено публічні властивості `IsOpen` та `Capacity` для отримання інформації про стан потоку та розмір буфера.

Для роботи з даними додано методи:
* `Write(byte[] data)` — записує дані у потік;
* `Read()` — читає дані з потоку.

Перед виконанням читання чи запису перевіряється стан прапорця `_disposed`.

## Конструктори

Створено конструктор `MyMemoryStream(int size)`, який приймає розмір буфера, ініціалізує масив `_buffer` потрібного розміру та встановлює прапорець `_isOpen = true` (імітація виділення ресурсу).

## Патерн Dispose

У класі реалізовано стандартний патерн Dispose:
* **`Dispose(bool disposing)`** — захищений віртуальний метод. Якщо `disposing == true`, виконується звільнення керованих ресурсів. Скидається буфер `_buffer = null` і потік закривається (`_isOpen = false`).
* **`Dispose()`** — публічний метод інтерфейсу `IDisposable`. Викликає `Dispose(true)` та `GC.SuppressFinalize(this)`, щоб повідомити GC не викликати деструктор.
* **`~MyMemoryStream()`** — деструктор (фіналізатор). Викликає `Dispose(false)` у випадку, якщо метод `Dispose()` не був викликаний вручну.
