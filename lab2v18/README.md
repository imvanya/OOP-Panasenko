# Лабораторна робота №2 — Класи в C# (Варіант 18)

## Про проєкт
У цій роботі я реалізував клас `Bookstore` для опису книжкового магазину та попрацював з базовими концепціями ООП: приватними полями, властивостями, конструкторами, методами та деструктором.

## Реалізація

### Дані та перевірка
Клас має приватні поля `_name`, `_location` та `_booksAvailable`. Для роботи з ними створено властивості: `Name` i `Location` не дозволяють записувати порожні значення, а `BooksAvailable` працює тільки на читання.

### Конструктори
Написав два конструктори. Один приймає назву, адресу та кількість книг, а другий (порожній) перенаправляє виклик на перший через `this()`.

### Продаж книг
Метод `SellBook(string bookTitle)` зменшує кількість книг у магазині на 1 при кожному виклику. Якщо книги закінчилися, програма каже про це користувачу.

### Деструктор та очищення
Створено деструктор `~Bookstore()`, який сповіщає про видалення об'єкта. Щоб перевірити його роботу в кінці програми, використовується збирач сміття:

```csharp
GC.Collect();
GC.WaitForPendingFinalizers();

```
